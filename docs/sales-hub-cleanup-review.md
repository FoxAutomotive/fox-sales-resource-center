## Reuse and limitations

The existing catalog, evidence resolver, comparison engine, trim cards, field categories, glossary, colors, year-change evidence, and compact print format are reused. The application did not have a shared accessible modal shell, so `dialog.js` is the only new interaction primitive; both reference views share it. The standard-only adapter is a presentation layer over the existing comparison engine, not a new database or importer.

Missing manufacturer information remains missing and displays N/A. Why Upgrade deliberately makes no claim when comparable verified standard gains cannot be established (for example, different drivetrains or unverified predecessor equipment). Original optional-package claims remain available for audit, without appearing in the sales comparisons. No additional vehicle information was researched or changed.
